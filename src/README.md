# src

The pipeline behind `../index.html`. `../REBUILD.md` has the full recipe, the traps and the
expected values; this is the short version.

Downloads live in `raw/` and intermediates in `raw/out/`; neither is committed (about 1.4 GB,
and every file is refetched or regenerated by the scripts). Nor is `payload.json`: the built
page carries it, and `catalog/tools/unsplice.py` will pull it back out.

| script | does |
|---|---|
| `parse_sitemaps.py` | IKEA en-GB product sitemaps → one row per article (names, English description) |
| `categorise.py` | each name → the product category it is sold as |
| `fetch_wayback.py` | archived copies of the sitemaps, one per file per quarter, from July 2022 |
| `timeline.py` | when each name was on sale; cohort = year first seen |
| `fetch_wikidata.py` | second place list: settlements in SE, NO, DK, FI |
| `build_names.py` | Statistics Sweden first names → bearers by sex |
| `build_saldo.py` | SALDO lexicon → Swedish words, spellings, "kind of" parents |
| `parse_lar5.py` | Lars Petrus's IKEA Dictionary → one label per name (calibration set) |
| `gazetteer.py` | GeoNames and Wikidata place sets, and the shared spelling fold |
| `analyse.py` | the rule table in Python, as a cross-check on the page |
| `build_payload.py` | everything → `payload.json` (base64 typed arrays) |
| `inject.py` | `template.html` + `payload.json` → `../index.html`, then the catalog wrapper and breadcrumb |

Run from this directory with `python -P` (and `PYTHONIOENCODING=utf-8` on Windows).
